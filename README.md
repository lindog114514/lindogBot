# 使用说明 
###### 请确保你公网服务器并已经进行ICP备案(如果是国内的服务器)以及域名和SSL证书 
1. 克隆项目到本地
2. 创建虚拟环境并执行 pip install -r requirements.txt
3. 将获取到appid和secret填入到配置文件中 
4. 运行bot.py脚本
